DTO = Data Transfer Object

JWT = JSON Web Token 
    Είναι ένα string που παίρνει ο χρήστης όταν κάνει login σωστά.
    1. User κάνει login
    2. Backend ελέγχει password
    3. Backend επιστρέφει JWT
    4. Frontend κρατάει το JWT
    5. Σε κάθε protected request, frontend στέλνει:
    Authorization: Bearer <token>

    401 Unauthorized = δεν είσαι logged in / δεν έχεις σωστό token
    403 Forbidden = είσαι logged in, αλλά δεν έχεις δικαίωμα

    Το JWT_SECRET είναι ένα για όλο το backend, όχι ένα ανά χρήστη.
    Επειδή δεν είναι password χρήστη. Είναι το κλειδί του server για να υπογράφει tokens.

ANGULAR

npm i -g @angular/cli@21
ng new frontend

Αν θες standalone components να είναι false (module-based, όπως έχεις τώρα):

ng new frontend --standalone=false

Μετά κάθε component/service το φτιάχνεις με:

ng generate component users-component
ng generate service auth/auth

Κάτι που πρέπει να ξέρεις: Το Revoke δεν πετάει έξω έναν χρήστη που είναι ήδη logged in. 
Το JWT του ισχύει για 1 ώρα και το JwtStrategy.validate δεν ρωτάει τη βάση. 
Για τώρα είναι αποδεκτό, απλώς γράψ' το στα caveats του implementation-map. 
Αργότερα διορθώνεται αν το validate φορτώνει τον χρήστη και ελέγχει ότι είναι APPROVED.
