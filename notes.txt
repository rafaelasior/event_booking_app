NESTJS

nest -g install @nestjs/cli@11
nest new backend

Για backend πιθανότατα να χρειαστούν:

Μετά, τα κομμάτια που έχεις (auth, users, events, prisma) θα τα πρόσθετες σταδιακά με τη γεννήτρια, όχι copy-paste:

nest g module auth && nest g controller auth && nest g service auth
nest g module users && nest g controller users && nest g service users
                            ή
με την εντολή: nest g resource auth και nest g resource users <---- μελέτησέ το πριν το χρησιμοποιήσεις δίνει options να ξέρεις τι βάζεις κια γιατί

Και το Prisma το προσθέτεις ξεχωριστά (δεν έρχεται με το nest CLI):

npm install prisma --save-dev
npm install @prisma/client
npx prisma init
Αυτό είναι το σημείο που θα έφτιαχνες .env/.env.example από την αρχή


ANGULAR

npm i -g @angular/cli@21
ng new frontend

Αν θες standalone components να είναι false (module-based, όπως έχεις τώρα):

ng new frontend --standalone=false

Μετά κάθε component/service το φτιάχνεις με:

ng generate component users-component
ng generate service auth/auth
